# Тренажёр ЭБОД · АВД · УДО

Сайт: https://yarikchizhov2006-cpu.github.io/INSYSTEM/modul11/

Подготовка к экзамену по модулю 11: «Этичное и безопасное обращение с данными», «Анализ и визуализация данных», «Управление данными организации».

- 430 заданий и 90 карточек устного ответа по каждому из 90 экзаменационных вопросов.
- Три уровня сложности и семь форматов: один ответ, несколько ответов, верно/неверно, соответствие, порядок, ввод ответа, устный ответ с самопроверкой.
- Задания и варианты перемешиваются при каждом запуске.
- Режим билета: три вопроса, таймер на 30 минут, сверка с карточкой, тест по билету.
- Участники: каждый входит под своим именем и видит свой прогресс, ошибки и уровень («освоено N из 90»).

Прогресс хранится в браузере. Чтобы продолжить на другом устройстве, на экране участника скопируйте код переноса и вставьте его на втором устройстве.

Весь сайт — один файл `index.html`, без сборки и сервера.
